# CoderHub — tu workspace de búsqueda laboral

Tu espacio de trabajo con **CoderHub**. Lo abrís con **Claude Code** o **OpenCode** y desde acá mejorás tu CV, tu LinkedIn, tu perfil de GitHub y te preparás para entrevistas — con las herramientas y el método de la mentoría.

> Generado desde el template de CoderHub. Es tuyo y privado: tu perfil y todo lo que produzcas vive en `archivos-generados/`, a la vista, para que lo iteres.

## Arrancá acá

1. Abrí la carpeta con **Claude Code** (`claude`) o **OpenCode** (`opencode`).
2. Decile: **"configurá mi perfil"** (o `configurar-coderhub`). Llena `archivos-generados/perfil.md` desde tu CV, tu LinkedIn o la call de discovery. Es el primer paso — todo lo demás lee ese perfil.
3. Después pedí lo que necesites en lenguaje natural. El asistente elige la herramienta.

## Qué podés pedir

| Decís… | Hace… |
|---|---|
| "armá mi CV" | Genera tu CV en PDF con el método CoderHub |
| "adaptá el CV a esta oferta {JD}" | Tailorea el CV a una búsqueda puntual |
| "optimizá mi LinkedIn" | Reescribe tu perfil para que te encuentren los recruiters |
| "mejorá mi README de GitHub" | Arma un profile README que posiciona |
| "armá mi banner" | Banner de LinkedIn o GitHub |
| "preparame para la entrevista" | Prep técnica y conductual |
| "actualizá CoderHub" | Trae las últimas mejoras de las skills, sin tocar tu info |

## Dónde está todo

- `archivos-generados/` — todo lo tuyo: `perfil.md` + tus CVs, drafts de LinkedIn, prep de entrevistas. Editable, es tuyo.
- `.claude/skills/` — las herramientas de CoderHub. No hace falta tocarlas.
- `AGENTS.md` — instrucciones para el asistente (incluye la voz/tono).

## Mantenerlo al día

Pedí **"actualizá CoderHub"** cuando haya mejoras en el método: trae lo nuevo de las skills sin tocar `archivos-generados/`.
