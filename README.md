# CoderHub — tu workspace de búsqueda laboral

Este es tu espacio de trabajo con **CoderHub**. Lo abrís con **Claude Code** o **OpenCode** y desde acá mejorás tu CV, tu LinkedIn, tu perfil de GitHub y te preparás para entrevistas — con las mismas herramientas y el mismo método que usamos en la mentoría.

> Este repo se generó a partir del template de CoderHub. Es **tuyo y privado**: tu perfil y todo lo que produzcas vive acá, a la vista, para que lo iteres.

## Arrancá acá

1. Abrí la carpeta con **Claude Code** (`claude`) o **OpenCode** (`opencode`).
2. Decile: **"configurá mi perfil"** (o `coderhub-setup`). Va a llenar `perfil/profile.md` a partir de tu CV, tu LinkedIn o la call de discovery. **Es el primer paso — todo lo demás lee ese perfil.**
3. Después pedí lo que necesites en lenguaje natural. El asistente elige la herramienta sola.

## Qué podés pedir

| Decís… | Hace… |
|---|---|
| "armá mi CV" | Genera tu CV en PDF con el método CoderHub |
| "adaptá el CV a esta oferta {JD}" | Tailorea el CV a una búsqueda puntual |
| "optimizá mi LinkedIn" | Reescribe tu perfil para que te encuentren los recruiters |
| "mejorá mi README de GitHub" | Arma un profile README que posiciona |
| "preparame para la entrevista" | Prep de entrevista técnica y conductual |
| "actualizá CoderHub" | Trae las últimas mejoras de las skills (sin tocar tu info) |

## Dónde está todo

- `perfil/profile.md` — quién sos (lo llena `coderhub-setup`). **Editable, es tuyo.**
- `trabajo/` — lo que producís: `cv/`, `linkedin/`, `entrevistas/`.
- `.claude/skills/` — las herramientas de CoderHub (no hace falta que las toques).
- `AGENTS.md` — instrucciones para el asistente. `voz.md` — cómo habla.

## Mantenerlo al día

Cuando haya mejoras en el método, pedí **"actualizá CoderHub"**: trae lo nuevo de las skills **sin tocar `perfil/` ni `trabajo/`**.
